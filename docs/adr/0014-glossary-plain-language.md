# User, web app, Bot, encryption key

The persist names match the glossary. **User**, **web app**, **Bot**, and **encryption key** are the terms, including column and secret names. Home secret and Action input are `encryption_key`. D1 uses `bot_at`, `bot_installation_id`, and `encryption_key_meta`. sessionStorage prefixes use encryption-key. Local-dev flag is `LAB_DEV_USER`.

Do not use installer, control plane, poster, or VaultKey for those concepts.
